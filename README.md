# GCDBar

A global cooldown bar for World of Warcraft (retail 12.0). It turns green when you're inside the spell queue window.

## Install

Copy the `GCDBar` folder into `_retail_/Interface/AddOns/`.

## Commands

| Command | Effect |
| --- | --- |
| `/gcd unlock` | Show the bar so you can drag it |
| `/gcd lock` | Lock it in place |
| `/gcd size <w> <h>` | Set the size |
| `/gcd idle` | Toggle an empty bar in combat |
| `/gcd reset` | Default position and size |
